## 继续进行客户端验收

每个客户端都需分别完成，不复用另一客户端的结论：

1. 记录完整客户端版本、Windows 版本、入口类型和测试人。
2. 使用无其他自定义技能的测试账号或测试配置，准备官方发布的 starter ZIP。
3. 从文件管理器真正拖入 ZIP，发送“安装这个包”。记录 Agent 是否能读到 INSTALL.md 和 manifest.json。提供路径不能替代此项。
4. 观察 Agent 是否只选择当前宿主、是否正确处理必要权限、是否通过官方渠道获得固定版本工具并核对摘要。
5. 记录逐项文件安装、依赖和识别状态；重装一次确认 unchanged；本地修改技能后确认 conflict 且原内容保持。
6. 开启新会话，明确调用 skillport-brief 处理一段材料，验证实际输出与 `SkillPort brief ready`；再调用 skillport-checklist，验证验收表与 `SkillPort checklist ready`。
7. 调用技能管家搜索公开社区目录，安装一个未安装的固定版本单技能。记录公开下载和实际调用；没有在线 Release 时此项保持待验收。
8. 提交报告与最少必要证据。通过完整流程才能将相应客户端标记为 verified。

测试专用确认字符串只是行为观察线索，不能单独证明已从正确目录加载；需同时保留宿主技能发现或调用记录。
